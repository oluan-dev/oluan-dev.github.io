Sistema

Conexões

Tudo o que o atendente usa de fora, e o lugar para ligar os próximos sistemas: CRM, agenda, ERP, planilhas.

Webhooks de saída 0

A cada evento escolhido, o atendente manda um POST em JSON para o endereço. Serve para levar conversas a um CRM, a uma planilha ou a outro sistema. Se houver segredo, ele vai no cabeçalho Authorization.

Chaves de API 0

Guardadas na VM. O painel nunca mostra a chave inteira, só os 4 últimos caracteres. Nenhuma integração usa estas chaves ainda; elas ficam prontas para as próximas.

API do atendente entrada

Outros sistemas podem falar com o atendente por estes endereços, mandando o token do painel no cabeçalho x-token.
